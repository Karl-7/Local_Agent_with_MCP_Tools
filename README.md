Just download the zip, and click the "start.bat", it will create an icon also on your desktop, so you can click that in the future instead.
All your personal memories will be recorded in the "memory.json", which will be created once you start to use the app.
The model will try to record what it knows about you everytime after you stopped responding for a while, as well as when you close it.

you can also change the model at "start.bat" if you want, right now it's a 2B Qwen3.5, which can run on most of the laptops.

Have fun!
